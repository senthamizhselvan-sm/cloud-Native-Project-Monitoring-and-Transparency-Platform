2. FEATURES & INTEGRATIONS IMPLEMENTED
------------------------------------------------------------------------
- Multi-Service Axios Setup (`frontend/src/services/api.ts`):
  - Created `authApi` (default, pointing to port 8001) for authentication.
  - Created `projectApi` (named export, pointing to port 8002) for projects.
  - Automated injection of Bearer token header on both clients.
- User Session Email Capture (`frontend/src/pages/LoginPage.tsx`):
  - Captured user's profile email on login and stored it in `localStorage.user_email`.
- Dynamic Project List Page (`frontend/src/pages/ProjectListPage.tsx`):
  - Fetches and displays actual projects from projectApi.
  - Formats numbers into currency and binds links to details view.
- Dynamic Project Details Page (`frontend/src/pages/ProjectDetailsPage.tsx`):
  - Fetches project metadata and displays status badge, progress ring, 
    assigned engineer, timeline, and description from database.
- Interactive Officer Dashboard (`frontend/src/pages/OfficerDashboard.tsx`):
  - Automatically calculates total projects, active projects, completed 
    projects, and total budget using live API data.
  - Implemented a functioning form to create new projects and assign 
    engineers via POST /projects.
- Interactive Engineer Dashboard (`frontend/src/pages/EngineerDashboard.tsx`):
  - Automatically filters projects list to display only projects assigned 
    to the logged-in engineer's email.
  - Added a sidebar card with range-slider and status select to update 
    project completion and status via PUT /projects/{id}.
- Dynamic Navigation layouts (`Sidebar.tsx` and `TopNav.tsx`):
  - Renders sidebar nav links based on role (Officer, Engineer, Admin).
  - Displays user profile letters, full name, and role dynamically.
  - Integrated Sign Out button in the dashboard sidebar.
